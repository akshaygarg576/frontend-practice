# Frontend Component Practice Repo

This repository contains individual branches for different frontend components I built for practice. Each branch focuses on a single component, making it easy to review and navigate.

---

## 📂 Repository Structure

| Branch Name        | Description                                                                    |
| ------------------ | ------------------------------------------------------------------------------ |
| `main`             | Base setup (Create React App + TypeScript + Tailwind + Prettier configuration) |
| `feature/carousel` | Image carousel component with navigation and autoplay                          |
| `feature/comments` | Comments section with expand collapse, nested replies                          |

---

## 🛠️ How to Use

1. Clone the repository.
   ```bash
   git clone git@github.com:your-username/your-repo-name.git
   ```
2. Checkout any branch to see that component.
   ```bash
   git checkout carousel-component
   ```
3. Run the project.
   ```bash
   npm install
   npm start
   ```

---

## 💼 Why This Repo Exists

This repo is part of my frontend interview preparation. Each branch focuses on solving a common UI problem or component implementation, demonstrating my:

- Component structuring and reusability
- TypeScript usage
- State management (where necessary)
- Accessibility (where applicable)
- Thought process for real-world scenarios
